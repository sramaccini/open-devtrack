# Trademarks

«OpenDevTrack» identifies this project. The open-source licence of the code ([MPL-2.0](LICENSE)) gives no rights to it: the MPL itself says so (section 2.3).

## What you may do

- Use the name to refer to the project truthfully, for example «built on OpenDevTrack», «compatible with OpenDevTrack», «a fork of OpenDevTrack».
- Keep the name in an unmodified copy of the project, or in a copy that only adds packaging or configuration.

## What needs permission

- Distributing a modified version under the name «OpenDevTrack». A modified fork must take a different name.
- Using the name in the name of your own product, company or domain, or in a way suggesting endorsement by the project.

For permissions, open an issue in the repository.
